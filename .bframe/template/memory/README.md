# Mémoire du projet

Documents propres à ce projet : ce qu'on y décide et comment il est rangé.

- `reference/` : vision, cadrage et structure du projet.
- `notes/` : ce qui est en discussion, un fichier par fonctionnalité, avec un index.
- `tasks/` : ce qui est validé et à faire, avec un index.
