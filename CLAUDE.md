# bFrame, le dépôt source

Ce dossier contient la source de bFrame. Le README dit ce qu'est bFrame et où sont les choses.

- Tout changement de bFrame se fait dans `compte/`, jamais directement dans `~/.claude/`.
- Après un changement validé, proposer de le recopier sur le compte, et attendre l'accord : la copie change le comportement de tous les projets.
- Après la copie, vérifier que les fichiers du compte sont identiques à ceux de `compte/`.
- `archive/` est l'ancien bFrame, hors Git : ne rien y modifier, n'y lire que sur demande.
