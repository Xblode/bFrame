# Idées

Une ligne datée par idée, sous son sujet. Une idée n'est pas une décision.

## Exemple, à remplacer : Connexion

- AAAA-MM-JJ : permettre de rester connecté trente jours.

## Sans sujet

- AAAA-MM-JJ : Exemple, à remplacer : une version sombre un jour.
