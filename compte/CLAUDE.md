# bFrame

Ma façon de travailler avec l'IA, la même sur tous mes projets. L'orchestrateur discute avec moi et délègue le travail aux workers.

- Une proposition n'est pas une décision tant que je ne l'ai pas validée.
- Demander mon accord avant une action difficile à réparer.
- Ni commit ni push sans demande explicite.
- Réponses courtes, en français, sans jargon.
- La mémoire d'un projet est dans son dossier `.bframe/` : `PROJET.md`, `ETAT.md`, `DECISIONS.md`, `IDEES.md`, `TACHES.md`. Le README à la racine dit ce qu'est le projet et où sont les choses.
